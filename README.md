# 星际漫游 · Universe Explorer

面向亲子天文学习的 Three.js 浏览器太阳系探索器。简体中文 / English / 日本語。

## 运行

安装 Node.js 22 或更新版本，在项目目录运行 `npm run dev`，打开 http://127.0.0.1:5173 。无需安装依赖：固定版本 Three.js 0.180.0 已包含在 `dist/vendor`，贴图保存在本地。可将 `dist` 整个目录部署到任意静态网站服务器；不要直接以 file:// 打开。

## 内容和交互

- 太阳、八颗行星、二十颗精选卫星；天体近景与太阳系总览。
- 拖动旋转、滚轮/双指缩放、右键拖动平移；相机重置与全屏。
- 暂停、1/10/100/1000 天每秒、时钟重置，轨道/名称显隐。
- 八颗行星之间的双向霍曼转移计算与22秒航行动画，显示天数、日心轨道转移 Δv 和带方向的相位角。
- 三语教学说明、响应式移动布局、键盘控件、减少动态效果偏好。

## 科学模型

数值使用 NASA/JPL 的平均半径、轨道半长轴、恒星公转周期和赤道重力。巨行星重力参考云层，不是固体表面。

画面大小、轨道距离分别压缩。圆形共面轨道、示意初始位置、放慢自转；显示日期不是实时星历。月球以外的卫星颜色为示意。海卫一逆行。

飞行计算采用真实 AU 与太阳引力参数，假定理想窗口；动画的行星角速度由同一太阳引力参数推导，飞船按开普勒方程推进，终点与目标行星相交。画面沿用压缩距离，因此轨迹不是按真实尺度画出的椭圆。Δv 不含逃逸、捕获、地面发射、着陆、倾角及其他天体引力。动画过程中普通模拟时钟保持不变，飞行进度单独显示。

## 项目结构与扩展

- `dist/js/data.js`：与显示分离的天体数据、父子关系、三语科普。
- `dist/js/physics.js`：不依赖 UI 的物理计算。
- `dist/js/scene.js`：Three.js 渲染、相机、运动、轨迹。
- `dist/js/i18n.js`：UI 翻译。
- `dist/js/app.js`：界面和状态动作；可选 WebMCP 接口。
- `dist/CREDITS.txt`：数据、图像和许可证来源。

下一阶段银河系视图应使用独立场景与尺度管理，不把光年尺度直接塞进当前太阳系坐标。现有父子关系数据结构可继续用于恒星系。

## 验证
